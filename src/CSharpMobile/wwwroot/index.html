About

      
Free C# console runner for students. It uses Microsoft's real C# compiler (Roslyn) and .NET 8, running on your phone. Your files are saved in this browser.

      
Supports classes, generics, List, Stack, Queue, Dictionary, LINQ, exceptions, Console.ReadLine, ReadKey, Clear and colors. File access, threads and NuGet packages are not available.

      
Made by Generino P. Siddayao, CICS, Cagayan State University.
